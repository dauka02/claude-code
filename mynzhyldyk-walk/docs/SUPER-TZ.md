Это ТЗ самодостаточно: новая сессия без прежнего контекста обязана выполнить его,
опираясь ТОЛЬКО на этот документ + файлы репозитория + приложенные PDF.

## 0. Роль и главный принцип

Ты — техлид проекта 3D-прогулки по мастерплану аллеи Мыңжылдық (Астана).
ГЛАВНОЕ ПРАВИЛО: ничего «на глаз» и «как красивее». Каждый объект, форма,
позиция, материал — только из референсов (страницы отчёта, фото, презентация).
Если референс неоднозначен — спроси заказчика, не выдумывай. Текущая сцена —
рабочая болванка (~основные слои есть), задача — точность и сходство.

## 2. Архитектура кода (не ломать, дорабатывать)

Данные: `tools/plan_points.json` (оцифровка страниц по сетке) → `npm run trace-plan`
→ `src/data/alm.json` (спайн, кварталы 0-6596 м, дороги, LRT, река, озёра galaxy/
mynzhyldyk, полигон участка, маркеры 1-30, POI) → `npm run gen-trees` →
`src/data/trees.json` (~17k деревьев). РЕНДЕР ЧИТАЕТ ТОЛЬКО ЭТИ JSON.
`src/data/geo.ts` — рантайм: spineAt/perp/bandHalf/arcOf/nearLine(kinds)/inSite/
heightAt (шум+холмы+русла+бермы, ступенчатое сглаживание у дорог/дорожек).
Сцена: `src/scene/*` (Terrain — зонирование город/луг/степь + шейдер-гашение травы;
Roads; Water; LRT + виадук Калдаяковой; Buildings — периметральные кварталы,
NurlyZhol; Vegetation — 6 видов + цветущие + 3 вида цветочных куртин; Life —
фонари/лавки/машины/люди; AlleyPlay — игровые башни + ступени берм; Atmo).
Кварталы: `src/quarters/Quarters.tsx` (Millennium/CentralPark/Hub/Station/Yesil),
`src/quarters/KazakEli.tsx` (ансамбль площади). Управление: `src/controls/Controls.tsx`
(walk/drone/flyover, клик-телепорт; при ?debug=1 есть `window.__tp(x,y,z,lx,lz)`).

## 3. Что уже сделано и в каком качестве

бермы+луга многолетников+цветущие деревья; периметральная застройка у кромки;

## 4. ЗАДАЧИ (по приоритету; после каждого блока — верификация и деплой)

### Блок 2. Растительность слоями (эталон стр.9-10)
Кустарниковый ярус: объёмные массы кустов (инстансы: 2-3 меша-«облака» flatShading

Цветники НЕПРЕРЫВНЫМИ бордюрами по кромкам дорожек (сейчас — россыпь): сеять куртины
плотной полосой 1.5-2.5 м вдоль walk/bike с обеих сторон (шаг ~1.2 м, смесь 3 видов).
Деревья: разброс масштабов 0.6-1.8, у дорожек кроны нависают (посадка в 3-5 м).

### Блок 3. Наполнение аллеи
Кафе-павильоны с зонтами у активных фасадов (каждые ~400 м), перголы, тотемы

пиктограммы (канвас-декали каждые ~60 м).

### Блок 4. Привокзальный парк точно по плану стр.25/27
Форму озера взять с плана (не эллипс) — оцифровать контур в plan_points и вести

### Блок 5. Центральный парк (стр.52 отчёта, стр.11 презентации)

### Блок 6. Полировка картинки
SSAO (N8AO) на high; contact-подобные тени; больше вариаций фасадных текстур
(генерить Higgsfield по стилю фото Астаны); LOD-разгрузка дальних инстансов.

## 6. Технические грабли среды (сэкономят часы)

- Из dev-среды cloudfront НЕДОСТУПЕН (прокси 403; vercel.app тоже) — НЕ пытаться
  обходить. Локально работают процедурные фолбэки; на Vercel ассеты качаются сами.
- Скрин-проверка: `npm i -D playwright pngjs`; chromium `/opt/pw-browsers/chromium`
  с args `--use-angle=swiftshader --enable-unsafe-swiftshader --no-sandbox`;
  ждать load+10 c (SwiftShader ~1.5 fps); клики через page.evaluate; телепорт —
  `window.__tp(...)` при `?debug=1`; метрики `window.__gl.info` (calls/triangles).
  После проверки: удалить *.tmp.mjs, `npm uninstall playwright pngjs`.
- `pkill -f vite` убивает сам bash-вызов (матч по своей команде) — использовать
  `pkill -f 'v[i]te'`.
- mergeGeometries: НЕ смешивать indexed/non-indexed — `.toNonIndexed()` перед слиянием.
- Read картинок иногда даёт «media removed» — тогда pngjs-анализ регионов пикселей.
- Шелл сбрасывает cwd между вызовами — всегда `cd /home/user/claude-code/mynzhyldyk-walk`.
- Бюджеты: ≤400 draw calls, ≤3.5 млн треугольников (сейчас ~230/480k — запас есть).
- tsc: `npx tsc -b` из папки проекта; сборка `npm run build`. Оба должны быть чистыми
  перед каждым коммитом.
