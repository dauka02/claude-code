# Green Line — интерактивная 3D-прогулка (Этапы 1 и 2)

First-person прогулка по бульвару **Green Line (Астана)** — линейному парку 60 м
шириной. Две очереди: **1 этап** Култегін → Анет баба (721 м + рукав вдоль
ул. Айтеке би), **2 этап** Омарова → Култегін и Анет баба → Толе би (1280 м,
на этапе проектирования). **Планировочная геометрия построена по генпланам из
презентаций** (см. «Пайплайн генплана»), а не «на глаз».

**Стек:** Vite · React · TypeScript · Three.js · @react-three/fiber · drei ·
@react-three/postprocessing · zustand. Ассеты (PBR-текстуры, hero-GLB)
сгенерированы через **Higgsfield MCP** — 28 генераций, список в `docs/assets.md`.

## Запуск

```bash
npm install
npm run fetch-assets   # скачать Higgsfield-текстуры и GLB (рекомендуется)
npm run dev            # http://localhost:5173
npm run build          # production-сборка (fetch-assets на Vercel запускается сам)
```

Без ассетов приложение полноценно работает на процедурных фолбэках.

|---|---|---|
| Движение | **WASD** / стрелки | джойстик слева |
| Обзор | мышь (PointerLock) | свайп справа |

| День / ночь | **N** или кнопка | кнопка |

1 этапе, 12 на 2 этапе. Внизу — миникарта с реальной геометрией сегмента.

## Пайплайн генплана (единственный источник геометрии)

1. Страницы-схемы генплана растеризованы в `tools/plans/` (200 dpi):
   ОМАРОВА-КУЛТЕГІН, общий план крыла B (2 пруда + круглая площадь-кольцо),
   детали АНЕТ БАБА и ТОЛЕ БИ; спутниковая ситуационная схема; аэрорендер 1 оч.
2. По сетке (`tools/grid_overlay.mjs`) сняты контрольные точки путей, вело,
   беговых, прудов, площадей, лужаек → `tools/plan_points.json` (пиксели плана).
3. `npm run trace-plan` (`tools/trace_plan.ts`) калибрует масштаб (длины улиц по
   спутнику: Култегін→Анет баба = 721 м) и пишет **`segments/stage1.json`,
   `segments/stage2.json`** в мировых метрах + контрольный оверлей
   `tools/plans/overlay_check.png` (геометрия поверх генплана — формы совпадают).
4. Рендер читает ТОЛЬКО эти JSON: `src/data/geometry.ts` строит кривые, рельеф,
   хэш-сетку расстояний; все ленты/пруды/площади/лужайки — из JSON.

## Зоны

**Этап 1:** западный вход (Култегін) → тихие сады с косами троп → пруды с
куланом (~6 м, ламели) и игровой зоной → развязка Айтеке би (спорт-корт,
рукав 65 м на юг с вело) → дождевые сады с мостками → входная площадь со
стелой THE GREEN LINE (Анет баба). Подпорные стены: тип 1 — 48 шт (695,9 м),
тип 2 — 4 шт (136 м), на каждой третьей — угловая деревянная скамья.

**Этап 2, крыло B (Анет баба → Толе би):** лужайка со сценой в кольце изгороди →
пруд 1 + детская площадка → рощи и перголы → **центральная зона**: круглая
площадь-кольцо, мокрый фонтан (частицы), каскадные террасы с тюльпанами,
2 скальных водопада (шейдерные завесы), 2 тоннеля из арх. бетона → сухой
фонтан → городской лес → пруд 2 + площадка → вход GREEN LINE (стела
металл-буквы, пергола, кирпичные скамьи, диск-панно). На горизонте — силуэты
Хан Шатыра и пирамиды Дворца мира.

**Этап 2, крыло A (Омарова → Култегін):** городской лес, аллея, беговые
дорожки (оранжевые), велодорожка, детская площадка, парковочные карманы.

## Структура

```
segments/stage1.json, stage2.json — планировочная геометрия (из генплана)
tools/trace_plan.ts               — оцифровка генплана → JSON + оверлей-проверка
tools/plan_points.json            — контрольные точки со схем (пиксели)
tools/plans/                      — растеризованные схемы + overlay_check.png
src/
  data/geometry.ts     — рантайм-модель сегментов: кривые, рельеф, размещение
  store.ts             — этап, день/ночь, качество, полёт, прогресс, порталы
  world/Boulevard.tsx  — рельеф, мощение, вело/бег, площади, стены, мостки
  world/Vegetation.tsx — 6 пород (instancing), трава с ветром, тюльпаны, валуны
  world/Water.tsx      — пруды, мокрый/сухой фонтаны (частицы), водопады (шейдер)
  world/Buildings.tsx  — кварталы-контекст + ландмарки горизонта
  world/Props.tsx      — фонари 8,5 м/3000К, скамьи, стелы, кулан, корт, порталы
  world/PropsStage2.tsx— перголы, тоннели, каскады, лужайка-сцена, вход Толе би
  player/Controls.tsx  — FPS + полёт + мобайл + переходы между этапами
  ui/InfoPoints.tsx    — маяки-инфопоинты (ru.json), ui/HUD.tsx — миникарта из JSON
docs/reference.md      — выжимка из трёх презентаций
docs/assets.md         — все URL генераций Higgsfield
```

## Производительность

InstancedMesh/merge для всего повторяемого; < 120 draw calls на сегмент;
активен один сегмент за раз (стриминг); тени только у игрока; 2–4 живых
PointLight ночью; dpr ≤ 1.5; High/Low; туман ослабевает на высоте (аэровиды).

## Деплой на Vercel

Import → Root Directory **`greenline-tour`** → Deploy. `vercel.json` сам
подтянет Higgsfield-ассеты при сборке (фолбэк — процедурные текстуры).
