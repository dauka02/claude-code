# Бульвар Greenline — интерактивная 3D-прогулка

First-person прогулка по бульвару **Greenline (1 этап, Астана)** — линейному парку
721 × 60 м между жилыми кварталами. Построено по ландшафтной презентации проекта:
6 зон, 1 104 дерева (6 пород), дождевые сады, пруды, игровая и спортивная зоны,
подпорные стены со встроенными скамьями, фонари 8,5 м с тёплым светом 3000К.

**Стек:** Vite · React · TypeScript · Three.js · @react-three/fiber · drei ·
@react-three/postprocessing · zustand. Ассеты (PBR-текстуры и hero-модели GLB)
сгенерированы через **Higgsfield MCP** (`docs/assets.md`).

## Запуск

```bash
npm install
npm run fetch-assets   # скачать сгенерированные текстуры и GLB (опционально)
npm run dev            # http://localhost:5173
npm run build          # production-сборка в dist/
```

Без `fetch-assets` приложение полностью работоспособно: каждая текстура и модель
имеет процедурный фолбэк, файлы подхватываются автоматически при появлении в
`public/assets/`.

## Управление

| Действие | Desktop | Mobile |
|---|---|---|
| Движение | **WASD** / стрелки | джойстик слева |
| Обзор | мышь (PointerLock) | свайп справа |
| Бег | **Shift** | — |
| Режим полёта | **F** (Space/C — вверх/вниз) | кнопка «Полёт» |
| День / ночь | **N** или кнопка | кнопка |
| Пауза | **Esc** | — |

Подойдите к зелёному маяку ближе 3,5 м — откроется карточка с данными проекта
(8 инфопоинтов: цифры, зоны, породы деревьев, освещение).

## Зоны бульвара (юг → север)

| Метры | Зона |
|---|---|
| 0–80 | Входная площадь, стела THE GREEN LINE |
| 80–220 | Дождевые сады, деревянные мостки |
| 220–360 | Пруды, каменистые берега, террасы |
| 360–500 | Игровая зона, скульптура-кулан ~6 м |
| 500–620 | Спортивная зона, баскетбол |
| 620–721 | Тихая зона, извилистые тропы, выход |

## Структура

```

  App.tsx               — Canvas, сцена, HUD
  store.ts              — zustand-состояние (день/ночь, качество, полёт, прогресс)
  world/constants.ts    — геометрия мира: путь-серпантин, зоны, пруды, рельеф
  world/geometry.ts     — ленты/стены/блобы вдоль кривых
  world/textures.ts     — загрузка Higgsfield-текстур + процедурные фолбэки
  world/Boulevard.tsx   — рельеф, мощение, гравий, подпорные стены (48+4), мостки
  world/Vegetation.tsx  — 6 пород деревьев (instancing), трава с ветром, валуны
  world/Water.tsx       — пруды с отражением и рябью
  world/Buildings.tsx   — жилые кварталы 12–18 эт., ночные окна (emissive)
  world/Props.tsx       — фонари 8,5 м, скамьи, стела, кулан, площадка, болларды
  world/Atmosphere.tsx  — небо день/ночь, туман FogExp2, солнце и фонари
  world/Effects.tsx     — bloom + vignette (High)
  player/Controls.tsx   — FPS-контроллер, полёт, границы, коллизия с водой
  ui/InfoPoints.tsx     — 8 маяков с карточками (ru.json)
  ui/HUD.tsx            — стартовый экран, шкала-миникарта 721 м, тумблеры
  ui/TouchControls.tsx  — мобильный джойстик + drag-обзор
docs/reference.md       — выжимка из презентации (все цифры и материалы)
docs/assets.md          — URL всех генераций Higgsfield
scripts/fetch-assets.mjs — скачивание ассетов в public/assets/
```

## Производительность

- Всё повторяющееся — InstancedMesh / merged geometry (деревья, трава, фонари,
  скамьи, стены, валуны); суммарно < 100 draw calls.
- Тени — только вокруг игрока (следящая shadow-camera 110 м); PCFSoft.
- Ночью реальных PointLight всего 2–4 — переставляются к ближайшим фонарям,
  остальные светят emissive + спрайты-гало.
- `dpr` ≤ 1.5; переключатель качества High/Low (тени, постпроцессинг, плотность
  растительности, разрешение).

## Деплой на Vercel

Import → Root Directory: `greenline-tour` → Framework: Vite. Build
`npm run build`, output `dist/`. Чтобы в продакшене были Higgsfield-ассеты,
выполните `npm run fetch-assets` до сборки (или закоммитьте `public/assets/`).
