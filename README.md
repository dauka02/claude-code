# 🪧 AI Signage Pre-Check Agent

Внутренний AI-ассистент для **первичной проверки** заявок на размещение вывесок
и наружной рекламы.

Агент **не принимает финальное решение** и **не заменяет сотрудника**. Его
задача — быстро провести предварительный анализ материалов заявки, выявить
возможные нарушения требований дизайн-кода, подсветить риски и подготовить
черновик замечаний для менеджера. **Финальное решение всегда остаётся за
ответственным сотрудником.**

## Что умеет агент

Пользователь загружает материалы заявки (изображение фасада, эскиз вывески, PDF,
описание, адрес, параметры конструкции), а агент сравнивает их с базой правил
дизайн-кода и формирует структурированный предварительный отчёт:

1. краткое резюме заявки;
2. предварительный статус: **соответствует / есть риски / требуется ручная проверка**;
3. список возможных нарушений;
4. объяснение, почему это может быть нарушением;
5. ссылку на соответствующее правило из базы;
6. рекомендации по исправлению;
7. черновик ответа заявителю;
8. список вопросов для уточнения у заявителя или менеджера.

Под капотом — **Claude Opus 4.8** с поддержкой изображений и PDF и строгим
структурированным выводом (structured outputs).

## Структура проекта

```
signage_precheck/          # ядро (не зависит от UI — легко обернуть в FastAPI)
├── models.py              # ApplicationInput + схема отчёта PreCheckReport
├── rules.py               # загрузка базы правил
├── rules_base.yaml        # ПРИМЕРНАЯ база правил дизайн-кода (замените на свою)
├── prompts.py             # системный промпт агента
├── io_utils.py            # подготовка изображений/PDF в content-блоки
├── agent.py               # SignagePreCheckAgent — вызов Claude
└── render.py              # форматирование отчёта (Markdown / текст)
app.py                     # Streamlit-интерфейс для менеджера
cli.py                     # запуск из терминала
```

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env        # и вписать ANTHROPIC_API_KEY
```

## Запуск

**Веб-интерфейс (Streamlit):**

```bash
streamlit run app.py
```

**Из терминала (CLI):**

```bash
python cli.py \
  --address "ул. Пушкина, 10" \
  --description "Вывеска кафе, объёмные световые буквы, баннер ПВХ" \
  --construction "Длина 6 м, высота 0.8 м, подсветка контражур" \
  --image facade.jpg --image sketch.png \
  --pdf application.pdf

# JSON-вывод для интеграции:
python cli.py --description "..." --json
```

**Как библиотека:**

```python
from signage_precheck import ApplicationInput, SignagePreCheckAgent

agent = SignagePreCheckAgent()
report = agent.analyze(ApplicationInput(
    description="Вывеска кафе…",
    address="ул. Пушкина, 10",
    image_paths=["facade.jpg"],
))
print(report.status.value)
for v in report.violations:
    print(v.title, "→", v.rule_reference)
```

## Своя база правил дизайн-кода

`signage_precheck/rules_base.yaml` содержит **примерные** правила — замените их
на ваши реальные. Формат каждого правила:

```yaml
- id: SIZE-01
  category: "Размеры"
  title: "Высота настенной вывески"
  requirement: "Высота не должна превышать 0,5 м…"
  reference: "Дизайн-код, п. 3.1"
  severity: средняя        # низкая | средняя | высокая
```

Можно указать свой файл через переменную окружения:

```bash
export SIGNAGE_RULES_PATH=/path/to/my_rules.yaml
```

или флагом CLI: `python cli.py --rules my_rules.yaml ...`

## Важно

Это инструмент **ускорения первичной проверки** и снижения ручной рутины.
Все выводы агента носят предварительный характер; ответственность за финальное
решение несёт сотрудник.
